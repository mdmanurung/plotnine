Datasets
========

.. currentmodule:: plotnine_extra.data

The bundled datasets are small pandas data frames used by examples and tests.

.. data:: ToothGrowth

   Tooth growth measurements for guinea pigs given different vitamin C dose
   levels and delivery methods.

.. data:: penguins

   Palmer penguins measurements with species, island, body size, and sex
   columns.

.. data:: iris

   Iris flower measurements with species labels.

.. data:: wine

   Wine chemistry measurements with class labels.

.. data:: flights

   Monthly passenger totals for the classic airline flights dataset.
