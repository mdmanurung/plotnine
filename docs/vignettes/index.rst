Vignettes
=========

Worked examples organized by plotting task. Start with the quickstart, then
use the page that matches the API area you need.

Guide to the pages
------------------

``quickstart``
   Import style, plotnine syntax, constructors, and composition.

``statistical-annotations``
   Global tests, pairwise brackets, paired tests with ``wid``, manual
   p-value placement, and p-value formatting helpers.

``geoms-and-positions``
   Dense points, categorical point placement, labels, margins, raster-like
   polygons, and Tufte summaries.

``facets-guides-strips``
   Extended facets, per-panel scales, manual designs, axis guides, strip
   descriptors, panel-specific layers, and dendrogram scales.

``themes-palettes-scales``
   ggthemes-style palettes and scales, publication themes, styling helpers,
   palette lookup functions, and scale utilities.

``plot-constructors``
   ggpubr- and plotthis-style constructors for grouped, distribution,
   scatter, volcano, embedding, and ROC plots.

``composition-and-export``
   Operator composition, ggpubr-style arrangement helpers, figure annotations,
   rendered-plot inspection, and animation setup.
